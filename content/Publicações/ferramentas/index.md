Uma plataforma de **Business Intelligence (BI)** moderna funciona como uma linha de produção industrial: ela capta a matéria-prima (dados brutos), processa, refina e entrega o produto final (relatórios e insights) para os tomadores de decisão.
Esse ecossistema é dividido em **quatro camadas principais**, cada uma com ferramentas específicas.

### 1. Camada de Fontes de Dados (Data Sources)

É onde os dados nascem. A plataforma de BI precisa se conectar a múltiplos sistemas para extrair informações relevantes.

### 2. Camada de Ingestão e Processamento (ETL / ELT)

Nesta etapa, as ferramentas realizam o processo de Extração, Transformação e Carga (ETL). Os dados são limpos, padronizados e enriquecidos para que façam sentido juntos.

### 3. Camada de Armazenamento e Modelagem (Data Repository)

Os dados processados precisam ser guardados em um local seguro, centralizado e otimizado para consultas rápidas. Aqui o modelo de negócios é estruturado (como os esquemas Estrela ou Floco de Neve).

### 4. Camada de Visualização e Consumo (Data Visualization / Analytics)

É a ponta final do processo, onde os usuários de negócios interagem visualmente com os dados por meio de dashboards, gráficos e relatórios interativos.
